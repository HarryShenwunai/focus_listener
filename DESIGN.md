# Focus Listener visual system

- **Use scene:** a low-distraction classroom overlay used beside other software.
- **Palette:** deep ink `#17211B`, muted green-grey `#66736B`, primary green `#237A57`, soft green `#E4F3EB`, warm warning `#FFF1CD`.
- **Typography:** Microsoft YaHei UI for reliable Chinese/Latin rendering; 14px controls, 21–27px primary headings, 11–12px supporting status.
- **Shape:** 12–16px panel radii and one wide, soft offset shadow on the main overlay. Pills are reserved for status badges.
- **Motion:** only the candidate-ready breathing cue, and only when Windows animations are enabled.
- **Accessibility:** visible keyboard focus, system high-contrast brushes, text wrapping, logical tab order, and live status announcements.
- **Brand icon:** deep-green rounded square, two concentric focus rings, white centre point, and one subtle listening arc.
