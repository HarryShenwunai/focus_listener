# Focus Listener

一个 Windows 课堂注意力复位小组件。它在听课途中识别数学、科学、历史、语言及其他学科中完整、可复述的知识关系，自动弹出不要求计算的三选一问题，也支持 `Ctrl + Shift + Q` 手动触发。

当前仓库包含可运行的 MVP：

- `.NET 10 + WPF` 置顶悬浮窗口；
- 六类通用知识点：定义、因果、规则/条件、过程/顺序、比较/区分、分类/举例；
- 公式、数字和变量关系可以触发，但题目不会要求代入、计算、列式或求值；
- 默认 60 秒预热、自动题关闭后 120 秒冷却、最多 3 个候选知识点；
- 8 秒答题窗口，可延长一次至总计 20 秒，超时后保留 2 分钟待答徽标；
- 答题后显示正确性与课堂原话 3 秒；
- Windows 麦克风与系统播放设备可分别选择并记忆，支持自动选择、仅麦克风、仅系统声音和智能混合四种模式；
- Windows 麦克风与系统播放双路采集，按 100 ms 时间桶对齐；系统声活跃时优先系统声，否则回退麦克风，不做 PCM 混音；
- 可独立开关实时转写与半透明置顶字幕窗；临时文字只用于字幕，最终文字才允许进入出题；
- Gemini Live 实时转写与 Gemini Flash-Lite 一次结构化完成学科、知识类型、资格、质量、题目及证据判断；
- “一键系统检测”用 15 秒同时检测所选麦克风、所选系统输出、安全测试音、Gemini、实时转写、真实转写出题和本地导出；
- “一键系统检测”使用本次真实转写和正式课堂的同一套出题规则；
- 本地 SQLite 事件记录和 CSV 导出，不保存原始音频或完整课堂转写；
- 无 API Key 时可直接使用内置多学科模拟课堂。

## 运行

需要 Windows 10 19041 或更高版本，以及 .NET SDK `10.0.400`。

```powershell
dotnet run --project src/FocusListener.App/FocusListener.App.csproj
```

首次启动默认为模拟模式。点击窗口顶部的模式说明可配置 Gemini API Key；密钥保存到当前 Windows 用户的凭据管理器，不写入仓库或 SQLite。也可以在启动进程前设置 `GEMINI_API_KEY` 环境变量。

配置密钥后，应用使用：

- 实时转写：`gemini-3.1-flash-live-preview`
- 资格判断与三选一生成：`gemini-3.5-flash-lite`

模型名集中在 `GeminiFocusOptions`，可随 Gemini 模型生命周期调整。

## 使用

1. 点击窗口顶部配置 Gemini Key，或直接进入模拟课堂。
2. 打开“课堂提问设置”，分别选择实际使用的麦克风和系统播放设备，再选择音频模式。设备插拔后列表会刷新，但软件不会擅自改用别的设备。
3. 在同一设置页决定是否开启实时转写和独立字幕窗，并调整字幕透明度、字号及快捷键。
4. 点击“一键系统检测”。仅麦克风模式请朗读完整知识关系；仅系统声音模式请让电脑播放这段语音；软件也会自动播放轻柔测试音，并分别显示两路音量。
5. 只有本次实时转写收到最终文字时，检测页才会据此出题；没有文字或没有逐字证据时会明确不出题，不再使用固定素材代替。
6. 开始课堂后可在悬浮窗中随时更换设备、暂停转写、显示/隐藏字幕或重试 Live；出现“题目已准备”时可立即提问，也可等待自动触发。
7. 课堂结束后可导出分析 CSV。

默认快捷键：`Ctrl + Shift + Q` 立即提问，`Ctrl + Shift + S` 显示/隐藏字幕，`Ctrl + Shift + L` 锁定/移动字幕。字幕解锁后可拖动和调整大小，位置会自动保存。

“题目已准备”的呼吸动画可在设置中关闭；Windows 关闭动画效果时，应用也会自动尊重该系统设置。

## 验证

```powershell
dotnet build FocusListener.slnx
dotnet test tests/FocusListener.Tests/FocusListener.Tests.csproj
```

测试通过与桌面端相同的核心接口验证旧版答题行为，以及六类知识点、证据校验、无计算约束、危险内容拒绝、候选池排序与淘汰、预热/冷却、设置边界和 SQLite 向前迁移。

逻辑原型位于 `prototypes/focus-session-state.prototype.html`，可直接用浏览器打开。它是丢弃型状态机实验台，不属于生产代码。

## 本地数据

运行数据默认写入：

```text
%LOCALAPPDATA%\FocusListener\focus-listener.db
```

设置保存在 `%LOCALAPPDATA%\FocusListener\settings.json`。SQLite 和 CSV 记录学科/知识类型、候选质量与优先级、触发方式、题目、使用的课堂证据、答题正确性与耗时、生成失败原因以及淘汰/过期/报告事件；不会写入原始音频或完整课堂转写。

设置页中的“清除本地记录”只删除应用数据库和应用诊断目录，不删除已导出到其他位置的 CSV、设置或 Gemini 凭据。

## 线下验收

真实模式需使用自己的或明确获授权的课堂音频完成至少六类内容测试：数学关系/公式、科学因果、历史比较、语言定义、过程顺序、分类举例；同时验证残句、计算请求、无逐字证据和危险指令不会出题。另需覆盖清晰播放、远距离麦克风、噪声、中英混合和长停顿。

通用知识题规则见 `docs/universal-knowledge-questions.md`，架构决策见 `docs/adr/0001-use-native-windows-single-process.md` 与 `docs/adr/0002-universal-knowledge-candidate-scheduler.md`。
