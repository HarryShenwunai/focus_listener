# Focus Listener

Focus Listener is a quiet Windows classroom companion for adults and higher-education learners. Its primary outcome is an Attention Reset: a brief, evidence-grounded interaction that redirects attention to the lesson without becoming an assessment tool.

## Portable Beta contract

- Windows 10/11 x64, unsigned self-contained portable release.
- Simplified Chinese and English interface; lesson content keeps its original language.
- User-provided Gemini key, stored in Windows Credential Manager only after validation.
- Manual session end; optional one-time 15/30/45/60-minute reminder, off by default.
- No automatic telemetry or background update checks.
- Local analysis retention is 30 days; no raw audio or full transcript storage.
- GitHub issues and user-created sanitized support bundles are the support channel.

## Interface character

Operate mode. Preserve the calm green visual identity, compact always-on-top listener, clear recovery actions, native keyboard focus, Windows high contrast, and layouts that survive English text expansion and 200% scaling.
