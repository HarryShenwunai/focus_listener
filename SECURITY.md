# Security policy

## Supported version

Only the latest GitHub prerelease is supported during the Portable Beta.

## Reporting a vulnerability

Do not include API keys, classroom audio, transcripts, questions, evidence, or personal information in a public issue. Open a minimal issue at <https://github.com/HarryShenwunai/focus_listener/issues> asking for a private contact channel.

Focus Listener has no automatic telemetry. Use Help & About to create a sanitized diagnostic bundle, review it locally, and attach it only when appropriate.
